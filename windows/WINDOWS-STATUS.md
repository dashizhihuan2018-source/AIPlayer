# 万能AI播放器 V1.1.0 Windows preview1

沿用原公开源码的首页、搜索/发现、22来源、队列和Web操作界面，替换原AppKit/libmpv桥为Electron+Windows mpv JSON IPC。不是把Mac二进制改名；不包含OmniPlayer代码。

Windows安装器包含应用和原始Next服务。首次启动时，经明确确认，直接从mpv社区构建仓库下载固定日期的mpv和FFmpeg（合计约62MB），校验SHA-256后保留完整解压目录/原许可/下载来源；引擎不在本安装包内再分发，首次安装引擎需要联网，以后可离线播放本地文件。拒绝下载时仅保留网页模式，可以从「文件→打开媒体」重试安装。搜索等原有在线功能仍需网络。

实现：本机随机认证且只绑定127.0.0.1；原始UI；本地选择、URL和队列授权；mpv原生视频嵌入、播放/暂停/seek、倍速/音量/静音、音轨字幕/外部字幕、同步延迟、画面比例/旋转/调色、A-B/循环/逐帧；截图、GIF实时截图采样后编码、时间线海报、本地视频片段自动保存；窗口全屏。退出关闭本机服务和mpv，不删除用户配置/媒体。

差异与未验收：画中画、OCR、系统拖放/命令行文件关联、完整浮层遮挡与DPI/多屏、连续音画同步、GIF动态质量/4K高倍速和原生安装/升级/卸载尚未完成人工验收。GIF预览最多120秒/4500帧/512MB临时帧（达到即停止采样等待保存）；这不是Mac版300秒上限的对等通过。时间线海报/视频片段只处理用户已选择的本地文件；网络媒体不下载导出。GUI未通过项不得说已完成无损迁移。

安装包无代码签名，SmartScreen可能提示未知发布者；不应关闭系统保护。保留仓库AGPL及所有第三方许可；未再分发Apple SDK、Mac dylib或私人媒体/订阅/凭据。源代码与构建配置在对应Git分支；Windows预发布与原Mac发行包互不覆盖。
