# 公开源码与本机数据边界

本仓库使用独立干净历史，仅发布明确白名单的软件源码、测试源码、必要品牌/背景资产、许可及公开说明。不公开原私有开发历史、REA原始产物、商业应用二进制/提取资源、用户影片/PDF、截图/录屏、推广成片、音色参考、凭证、cookies、浏览/播放记录、诊断日志、安装回执或机器个人绝对路径。

## 本机目录

- 配置与随机认证：`~/Library/Application Support/LibreTV Desktop/`；认证文件权限0600，不打包进源码或App。
- WebKit设置/IndexedDB等：`~/Library/WebKit/cn.nankong.libretv.desktop/WebsiteData/`。更新不主动删除历史和设置。
- 截图、GIF和海报：`~/Pictures/AIPlayer/{Screenshots,GIF,Posters}/`。
- 视频片段：`~/Movies/AIPlayer/Clips/`。
- 本机日志/诊断：`~/Library/Logs/LibreTV Desktop/`。用户主动保存的诊断可能包含观看画面，分享前自行检查。

源码中的测试密码、example.test/example.com地址和临时测试文件是合成夹具，不是预置管理员、真实访问密钥或用户记录。应用没有默认云账号；本机loopback认证由安装版生成随机值，不应公开该值。

## 外部访问

影视查询、推荐、海报图片、订阅、播放与下载会访问所选第三方服务；对方可获知网络请求和IP。默认历史来源是公开接口地址，不意味着所有内容获授权。只使用自己有权访问、保存和分享的资源。

“发布为链接”会按用户动作把来源列表提交外部服务，不能当成本机保存；私人带密钥URL或内部订阅不要公开。此版本无集成AI服务、无默认模型密钥，不自动将本地影片交给AI。

## 审计范围

公开前检查实际Git暂存文件、符号链接、异常二进制、个人路径、常见密钥/私钥模式和敏感赋值；PNG/JPEG检查文字/EXIF元数据。只有生成品牌与背景图等必要资产可进入仓库，其他媒体和运行数据排除。

这是有界源码检查，不是完整安全认证、法律审查或恶意代码担保。未来更新仍需重新检查，不能仅依赖.gitignore或沿用本轮结论。
