# V1.1.8 / build24 全量快捷键对齐 OmniPlayer + 提示 5s 自动隐藏

版本 `1.1.8 / 24`。对齐 OmniPlayer Pro（本机）的全量可配置动作，并让状态提示 5 秒后自动隐藏。

## 背景

用户要求："对齐 OmniPlayer 所有的快捷键"——不是只覆盖常用 ⌘ 组合键层，而是把 OmniPlayer 二进制里 38 项可配置动作中 AIPlayer **有真实引擎/工具能力**的部分全部做出可达入口。本机 OmniPlayer Pro 用户偏好（已解锁取证）里没有任何自定义快捷键注册，基准即其官方默认键位表。

同时新增一条独立小需求：播放器顶部状态提示（"操作失败，请重试"等）显示 5 秒后自动隐藏。

## 改动

### 全量可配置动作（Web 白名单 + 原生「播放」菜单）

- **`upstream/src/components/desktop/desktop-workspace-logic.ts`**：
  - `MENU_SHORTCUT_ACTIONS` 白名单由 10 项扩到 40+ 项（定位/章节/帧步进、A/B、倍速、音/字幕轨道与延迟、GIF/录制片段/海报、书签、首/末项、字幕显隐与导入、画面比例循环、静音、窗口置顶等）。
  - 新增纯函数并附单测：
    - `stepSpeedValue`：倍速沿固定 0.25x–4x 阶梯步进，非档位值先吸附最近档再步进。
    - `chapterJumpIndex`：下一章取第一个晚于当前 +0.25s 的章节；上一章取最后一个早于当前 −0.5s 的章节；越界返回 null。
    - `cycleTrackId`：音/字幕轨道循环切换；字幕可选"无字幕"（-1）；无轨道被选中时无论方向都先选第一条实际轨道。
    - `stepDelayValue`：音/字幕延迟 ±0.5s 步进、±10s 上限（与设置面板 RangeField 一致）。
  - `DesktopWindowState` 增加可选 `alwaysOnTop` 字段，`parseWindowState` 同步严格校验。
- **`upstream/src/components/desktop/desktop-workspace.tsx`**：
  - `handleMenuShortcut` 全量路由：每个菜单动作落到对应的原生引擎命令、原生工具请求或 Web 状态变更；无真实能力的动作（如新建窗口）不进白名单、不虚构。
  - 状态提示 5 秒自动隐藏：新增 `useEffect`，`status` 非空时启动 5s 定时器清空；新提示覆盖旧提示重新计时；× 仍可立即关闭。
- **`desktop/main.swift`**：原生「播放」菜单由 10 项扩到 40+ 项（定位开头、首/末项、章节、帧步进、A/B、书签、倍速、静音、画面比例循环、音/字幕轨道与延迟、GIF/录制/海报/导入字幕、面板入口、画中画、窗口置顶、观看历史等），每项经 `emitShortcut` 桥接到 Web 层；⌘Q 退出仍走原生命令。
- **`desktop/NativePlayer.swift` / `desktop/NativeBridgePolicy.swift`**：
  - 新增原生 `alwaysOnTop` 请求（窗口置顶，对齐 OmniPlayer Always on Top）：`window.level = .floating` 并在 `UserDefaults` 持久化；PiP/全屏状态下拒绝并提示。
  - `capabilities()` 的 `commands` 列表加入 `alwaysOnTop`，Web 侧门控据此判断。
