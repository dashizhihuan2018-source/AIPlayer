# V1.1.5 / build21 点击画面切换播放/暂停

2026-11-11，macOS Apple Silicon。

## 原因与修复

桌面播放器的播放画面 `.video-surface` 原先只绑定双击进入全屏，单击没有任何处理；原生视频层 `hitTest` 返回 nil 后点击确实透传到网页层（双击进全屏可证明），因此单击中间画面不会暂停/播放。

修复：有媒体时单击播放画面切换播放/暂停，双击保持进入全屏；首页无媒体时单击不绑定，不误触播放器。复用既有 `togglePause` 意图通道，未新增命令。
