# V1.1.1 / build17 验证记录

2026-10-22，macOS Apple Silicon。

## 故障与修复

原生海报对 seek 完成后的实际时间使用固定小于 1 秒误差门限。自制 24 秒、1/3 FPS 视频可靠复现“媒体画面加载超时，海报未保存”：帧实际解码完成，但合法时间量化超过门限。改为参考实际帧间隔的有界容差，仍要求新的 playback-restart、非 seeking，不能用旧画面冒充定位成功。同一夹具在改前失败、改后通过。

海报改为 1200×1800 竖版电影构图，六个均匀时间点采样，按曝光/对比度选主图，三张辅图保留时间码。包含视频标题、固定模板推荐语、应用宣传及 GitHub 项目二维码。不是语义 AI 精彩片段识别或剧情生成；URL 标题只显示末段，不显示查询参数。

## 本轮验证

- NativePosterCaptureTests：竖版真实 PNG、Vision 解码二维码到准确项目地址、六帧采样、取消/晚回调、超时、失败、现有文件保护与输入边界通过。尺寸测试在改前失败。
- NativeMoviePosterTests：独立私有测试目录，不读取真实播放列表。自制低帧率、长视频和 UHD 视频生成通过，输出 1200×1800，二维码可解码。
- NativePosterEngineTests：长视频截图、OCR、GIF、海报及位置/暂停/解码器/A-B 状态恢复、普通停止取消通过。
- NativeToolFlowTests：实际截图/GIF/海报/MP4 自动保存、只回传文件名、写失败拒绝与关闭临时预览保留成果通过。
- 前端 42 个测试文件、483 项通过；TypeScript 检查通过。
- 生成的 UHD 测试海报已人工查看版式、文字、截图方向及二维码；测试图为自有合成素材，不冒充影片实拍海报。

复现测试：准备自有视频和原生依赖后，运行 `bash tests/run-movie-poster-tests.sh /absolute/path/to/owned-timecode.mp4`。使用 FFmpeg `testsrc2=size=640x360:rate=1/3` 生成 24 秒 MP4，传入 NativeMoviePosterTests 可复测低帧率分支。媒体不提交仓库。

## 边界

所有网络片源、直播、全部编码/帧率、其他 Mac、长期播放、手动点击完整流程未逐一验收。UHD 单独海报测试通过；旧综合测试的 UHD 样本没有烧录可识别时间码，其 OCR 断言不作为海报失败或本轮 OCR 修复。安装包为未经 Apple 公证的预览版；Windows 仍使用既有独立适配预览，本轮没有发布 Windows 海报修复。
