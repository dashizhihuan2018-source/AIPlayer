
# V1.1.7 / build23 快捷键对齐 OmniPlayer（含“关闭软件”入口）

提交 `0ebdf3f`，标签 `v1.1.7`，版本 `1.1.7 / 23`。46 文件/502 项测试通过、`npm run typecheck` 干净。

## 背景

用户要求：把“关闭软件”的快捷键也加进去，并对齐 OmniPlayer（本机 OmniPlayer Pro）的常用快捷键集。以 OmniPlayer Pro 的官方快捷键表为基准（空格/K 播放暂停、←/→ 快进退、↑/↓ 音量、Cmd+←/→ 上/下一项、Cmd+. 停止、Cmd+L 播放列表、Cmd+S 截图、Cmd+I 媒体信息、Cmd+Shift+P 画中画、Cmd+W 关闭当前、Cmd+Q 退出），把 AIPlayer 缺失项补齐并显性化“关闭软件”入口。

## 改动

- 新增原生「播放」菜单（`desktop/main.swift`），把 OmniPlayer 风格的播放控制键位落到 AppKit 菜单；每个项经 `NativePlayer.emitShortcut(action)` 桥接 `aiplayer:native` 的 `menuShortcut` 事件路由到 Web 层执行（播放队列与面板状态都在 Web 侧）：
  - ⌘Q 退出软件（原有，保留为“关闭软件”主入口）
  - ⌘W 关闭当前媒体（在线剧集经 `onBack` 返回影片页，否则停止）
  - ⌘. 停止播放
  - ⌘← / ⌘→ 上/下一项
  - ⌘L 显示/隐藏播放列表
  - ⌘S 截图
  - ⌘I 媒体信息（展开“媒体信息与播放偏好”分组）
  - ⌘⇧P 画中画
  - ⌘⇧O 观看历史
  - ⌘, 播放器菜单
- 方向键步进由 5s 改为 10s（与 OmniPlayer 一致）；Shift+方向键 ±60s 大跨度（桌面 `desktop-workspace.tsx` 与网页 `player-shell.tsx` 对齐）。
- “打开视频链接”由 ⌘L 改为 ⌘⇧L；浏览菜单“切换全屏”由 ⌘⌃F 改回 ⌘F。
- Web 层新增 `parseMenuShortcutEvent`（`desktop-workspace-logic.ts`，严格白名单 10 项动作，附单测）与 `handleMenuShortcut` 路由。
- 播放器菜单快捷键提示更新为全量 OmniPlayer 对齐清单（含 ⌘Q 关闭软件）。
- 顺带把 `desktop/Info.plist` 升版 1.1.7/23（保持紧凑单行格式，未复现 build21 的 PlistBuddy 重写回归）。
