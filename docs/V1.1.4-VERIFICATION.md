# V1.1.4 / build20 自动连播修复

2026-11-08，macOS Apple Silicon。

## 原因与修复

libmpv 使用 `keep-open=yes` 保留最后一帧，播放结束后会设置 `pause=true`。页面退出也会保护性暂停旧媒体。原先 `loadfile replace` 没有重置暂停状态，导致下一集虽然加载成功，却停在开头。

新媒体加载时明确设置 `pause=false`，本地队列、在线剧集和恢复进度共用此路径。不使用定时反复播放、不改自动连播开关或睡眠定时逻辑；用户加载后手动暂停仍有效。海报取帧、seek 和原有状态恢复路径未改变。

## 回归证据

- 新增真实 libmpv / NativePlayerController 集成测试：原代码报 `episode 2 loaded paused instead of autoplaying`，修复后通过。
- 连续三次播放到 EOF 再加载下一项，逐次检查加载回包 `paused=false`，且实际播放时钟推进。
- 页面退出仍暂停旧媒体，新媒体带恢复位置加载后自动播放；之后手动暂停，位置保持不动。
- 前端 45 个文件 / 492 项测试通过；TypeScript 检查通过。
- 独立只读审查未发现 Critical / Important 问题；修正测试夹具最短时长为三秒。
