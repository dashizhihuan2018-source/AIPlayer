# V1.1.3 / build19 验证范围

本轮修复透明顶栏的左键拖动，增加播放期间保持屏幕唤醒与保守的 HLS 广告自动快进，并把新导出海报的二维码改为 `https://dashizhihuan2018-source.github.io/AIPlayer-website/`。

## 自动化验证

- Web：45 个测试文件、492 项测试通过；TypeScript 检查通过。
- 原生桥：83 项校验断言通过；keepAwake 仅接受严格布尔值，拒绝额外字段。
- 原生窗口：验证顶部拖动带、左侧菜单/红绿灯、右侧资源按钮、画面区、全屏状态的命中边界；全屏转换保护保持通过。
- IOKit：实际取得并释放 PreventUserIdleDisplaySleep assertion；真实 libmpv 自有测试视频验证 idle/play/pause/resume/toggle/EOF/stop/shutdown。
- 广告：点播显式路径、闭合广告标记、合并区间、长度/时长限制、多画质一致性及拒绝直播/歧义输入；实际挂载 DesktopWorkspace，验证桥接 seek、每段一次、回退不强跳、关闭开关和持久化。
- 海报：实际 PNG 为 1200×1800；Apple Vision 解码新二维码为上述官网；取消、超时、失败时保持恢复行为。真实 libmpv 解码帧海报集成测试通过。

## 能力边界

- 广告快进不等于通用 AI 广告识别：只支持明确标记的 VOD HLS，单段不超过 180 秒，尾部不跳；多画质时间轴不一致时拒绝。正片内嵌广告、未知片源、直播不会猜测跳过。分析通过本机认证服务，沿用逐跳 SSRF 防护、超时和体积上限，不修改原播放列表。
- 每段每次分析只自动跳一次，不阻止用户手动回看。录制、GIF、导出或手动定位期间不自动跳。
- 防自动锁屏仅在实际播放时阻止闲置息屏；不关闭系统密码要求，不绕过手动锁屏、合盖或手动休眠。暂停/结束/退出后恢复系统正常行为。
- 自动化通过不代表用户观感已验收，也不代表另一台干净 Mac 已验证。签名仍为 ad-hoc，未 Apple 公证。构建中的既有 lint 和系统 API 弃用警告不冒充零警告。
- 已保存的旧海报不会被改写。用户截图、电影画面、播放地址、账号/本地设置及私有记忆不纳入公开提交与发布附件。
